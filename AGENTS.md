# Instructions for AI assistants

This repository is **Agentic Platform**, a local app built on Claude Code. The project rules are in `CLAUDE.md`, read all of it.

When the user wants to install or set up the city ("set up the platform", "set up my city", "setup", "install"), or `world.json` does not exist yet, follow `docs/SETUP.md` step by step. The city needs a signed-in Claude Code CLI (`claude auth login`), no matter which AI leads the setup.
